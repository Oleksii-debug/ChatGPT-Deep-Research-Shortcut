# ChatGPT Accessible Tool Picker

Доступне Chrome-розширення для NVDA, яке відкриває власне клавіатурне вікно вибору інструмента ChatGPT через **Ctrl+Shift+U** прямо з активного чату.

## Поточні інструменти

У версії 0.3.0 доступні саме три функції, підтверджені у живому меню ChatGPT:

1. **Створити зображення** — «Візуалізуйте все».
2. **Пошук в Інтернеті** — «Знаходьте актуальні новини й інформацію».
3. **Глибоке дослідження** — «Отримати докладний звіт».

## Як працює Ctrl+Shift+U

Після одноразового встановлення розширення **не потрібно відкривати `chrome://extensions` для запуску**.

1. Перебуваючи безпосередньо у будь-якому чаті на `https://chatgpt.com`, натисніть **Ctrl+Shift+U**.
2. Комбінацію обробляють два незалежні шляхи: Chrome Commands і клавіатурний listener у самій сторінці ChatGPT. Подвійне спрацювання дедуплікується.
3. Розширення відкриє власний доступний `role="dialog"` поверх поточного чату.
4. Фокус автоматично переходить на перший пункт.
5. **Стрілка вниз / вгору** або **Tab / Shift+Tab** переміщують вибір.
6. **Home / End** переходять на перший / останній пункт.
7. **Enter** запускає вибраний інструмент.
8. **Escape** закриває вікно й повертає фокус назад.
9. Після вибору розширення саме відкриває штатне меню ChatGPT `+`, знаходить відповідний пункт за доступною назвою/семантичними ознаками, натискає його та повертає фокус у поле запиту.

Комбінація навмисно працює навіть тоді, коли курсор уже знаходиться у полі введення ChatGPT.

Розширення **не надсилає ваш запит автоматично** і не змінює введений текст. Після активації інструмента ви продовжуєте працювати у звичайному полі запиту.

## Повноекранний і звичайний режим

Picker не прив'язаний до координат екрана або розміру вікна. Він використовує viewport-relative overlay (`position: fixed; inset: 0`) та адаптивні `vw`/`dvh` межі.

Тому той самий механізм призначений для:

- звичайного вікна Chrome;
- максимізованого вікна;
- браузерного fullscreen;
- ChatGPT із відкритою або закритою бічною панеллю;
- вузького або широкого viewport.

## NVDA

Діалог використовує:

- `role="dialog"`;
- `aria-modal="true"`;
- `aria-labelledby`;
- `aria-describedby`;
- звичайні HTML-кнопки для кожного інструмента;
- `role="status"` / `aria-live` для повідомлень про успіх або помилку.

Тому NVDA має оголосити назву діалогу, інструкцію та кожен пункт разом з описом.

## Чому це потрібно

У деяких поточних збірках ChatGPT меню `+` / «Додати файли та інше» існує в DOM і візуально відкривається, але його пункти можуть бути ненадійно доступні через NVDA. Розширення створює незалежний клавіатурний шар вибору, а потім виконує потрібну штатну дію без координат миші.

Воно орієнтується насамперед на семантичні ознаки:

- `data-testid="composer-plus-btn"`;
- `id="composer-plus-btn"`;
- `aria-haspopup="menu"`;
- доступні назви пунктів;
- `role="menuitem"` / суміжні ARIA-ролі;
- стабільні семантичні `data-*` ідентифікатори, якщо вони є.

Згенеровані CSS-класи ChatGPT не використовуються як основний механізм.

## Встановлення в Chrome

1. Завантажте ZIP з успішного GitHub Actions artifact або клон репозиторію.
2. Якщо це ZIP — розпакуйте його.
3. Один раз відкрийте `chrome://extensions`.
4. Увімкніть **Режим розробника / Developer mode**.
5. Виберіть **Завантажити розпаковане / Load unpacked**.
6. Виберіть папку, де лежить `manifest.json`.
7. Відкрийте або перезавантажте `https://chatgpt.com`.
8. Надалі запускайте picker **безпосередньо з чату** через **Ctrl+Shift+U**.

Якщо Chrome призначив цю комбінацію іншому розширенню, відкрийте `chrome://extensions/shortcuts` і призначте **Ctrl+Shift+U** команді цього розширення.

## Конфіденційність

- Розширення не робить власних мережевих запитів.
- Не збирає тексти чатів, prompts, cookies, токени або облікові дані.
- Працює лише на `https://chatgpt.com/*`.
- Дозвіл runtime мінімальний: `activeTab`.

## Розробка та перевірка

Node.js 20+ потрібен лише для тестів. Runtime-залежностей npm немає.

```bash
npm test
```

CI перевіряє код на Node 20, 22 і 24 та додатково виконує окремий release gate перед пакуванням. Перевіряються:

- синтаксис усіх JavaScript-файлів;
- семантичний matcher для всіх трьох інструментів;
- українські назви й підписи з живого меню;
- англійські fallback-назви;
- ARIA-контракт власного діалогу;
- клавіші Escape, стрілки, Home, End і Tab;
- прямий `Ctrl+Shift+U` у сторінці ChatGPT;
- фізичний `KeyU` незалежно від активної розкладки клавіатури;
- маршрутизація Chrome Command до активної вкладки;
- дедуплікація двох шляхів відкриття;
- viewport-relative layout для звичайного й fullscreen режимів;
- збереження введеного prompt і відсутність автоматичного submit;
- відсутність власних мережевих запитів і browser storage;
- Manifest V3 і мінімальні permissions;
- створення ZIP і SHA-256 checksum лише після повного green CI.

## Поточне обмеження

Автоматичні тести можуть перевірити код, manifest, shortcut-routing, accessibility contract та семантичний matcher, але вони не можуть повністю замінити один реальний acceptance-test у вашій авторизованій сесії ChatGPT + NVDA, тому що штатне меню ChatGPT формується динамічно на стороні вебклієнта.

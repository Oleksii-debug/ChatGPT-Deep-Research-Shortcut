# Доступні інструменти v0.5.0

Розширення Chrome для клавіатурного та NVDA-доступного вибору інструментів у вебчаті.

## Керування

- `Ctrl+Shift+U` — відкрити доступне меню.
- Стрілки вгору/вниз — вибір інструмента.
- `Enter` — активувати вибраний інструмент.
- `Tab` — перейти до кнопки діагностики.
- `Escape` — закрити меню.
- `Ctrl+Alt+Shift+D` — одразу завантажити діагностичний TXT останньої спроби.

## Інструменти

- Створити зображення.
- Пошук в Інтернеті.
- Глибоке дослідження / Поглиблене дослідження.

## Ключова гарантія v0.5.0

Клік по пункту меню не вважається успішною активацією. Успіх оголошується лише після стабільного підтвердження структурної мітки вибраного інструмента в composer. Розпізнаються inline selection-pill/token metadata, які використовує сучасний вебінтерфейс. Пункт меню, popup residue або звичайний текст запиту не є доказом активації.

Якщо підтвердження не знайдено, NVDA повідомляє «Не підтверджено…» і розширення не заявляє про успіх.

## Діагностика

TXT-звіт містить часову шкалу подій, стан кнопки `+`, факт знаходження/кліку native menu item, структурні metadata вибраного token, viewport/fullscreen і точну причину SUCCESS/FAIL. Текст запиту й чату не записується. Query/hash URL не записуються; для маршрутів розмов, спільних сторінок і проєктів динамічний ідентифікатор замінюється на `[redacted]`.

## Приватність

- немає власних мережевих запитів;
- немає `chrome.storage`;
- немає `chrome.downloads`;
- немає доступу до cookies;
- runtime permission — лише `activeTab`;
- content script обмежений `https://chatgpt.com/*`.
